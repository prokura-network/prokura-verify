# Contributing

Thanks for helping. This repository holds the Nachweis specification, its verifiers and examples for [Prokura](https://prokura.network). The gate and the core service are not in it.

## Good first contributions

- An example for another MCP client or agent framework (keep it runnable against the public demo).
- A verifier port (Go, Rust, Java…) that passes the fixtures in `fixtures/`.
- A case where a verifier here and [`docs/nachweis-format.md`](docs/nachweis-format.md) disagree. The specification is what we sign against; open an issue and we fix whichever is wrong.

## Ground rules

- **Run the tests** before you open a PR:
  ```bash
  cd verifier/typescript && npm ci && npm test
  cd verifier/python && pip install -e '.[test]' && pytest
  ```
- **Fixtures are real or clearly synthetic.** `fixtures/nachweis-demo-*.json` and `fixtures/root-*.json` come from our public demo and API; don't edit them, tests tamper with copies in memory. `synthetic-chain.json`, `synthetic-proofs.json`, `synthetic-rotation.json`, `merkle-vectors.json` and `jcs-vectors.json` are generated by `verifier/typescript/scripts/make-vectors.ts` with throwaway keys.
- **Say what was run.** Example code that has not been run end to end against the system it targets says so at the top.
- **No claims we can't back.** No performance, compliance or partnership claims in docs or examples.
- **No secrets, no personal data** in issues, fixtures or examples. The demo needs neither.
- Apache-2.0. By contributing you agree your contribution is licensed under it.

## Specification questions

If a rule in `docs/nachweis-format.md` reads as ambiguous, open an issue labelled `spec` and point at the section. We answer by fixing the specification, and the verifiers follow it.
