# Contributing

Thanks for helping. This repository holds examples and verifiers for [Prokura](https://prokura.network). The gate and core service are not in this repository.

## Good first contributions

- An example for another MCP client or agent framework (keep it runnable against the public demo).
- A verifier port (Go, Rust, Java…) that passes the same fixtures in `fixtures/`.
- Corrections where this repo and [prokura.network/llms.txt](https://prokura.network/llms.txt) disagree. The site is the source of truth.

## Ground rules

- **Run the tests** before you open a PR:
  ```bash
  cd verifier/typescript && npm ci && npm test
  cd verifier/python && pip install -e '.[test]' && pytest
  ```
- **Fixtures are real or clearly synthetic.** `fixtures/nachweis-demo-*.json` and `fixtures/root-*.json` came from the public demo and API. Don't edit them; tests tamper with copies in memory. `synthetic-chain.json` is generated by `verifier/typescript/scripts/make-vectors.ts` with a throwaway key.
- **Mark sketches as sketches.** Code under `integrations/` that wasn't run end to end says so at the top.
- **No claims beyond the site.** Describe Prokura only in terms prokura.network uses. No performance, compliance or partnership claims.
- **No secrets, no personal data** in issues, fixtures or examples. The demo needs neither.
- Apache-2.0. By contributing you agree your contribution is licensed under it.

## Spec questions

If the Nachweis rules look ambiguous, open an issue labelled `spec` and point at the line in `docs/nachweis-format.md`. Please don't change verifier behaviour to match a guess.
